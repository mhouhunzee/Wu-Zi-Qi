1.采用GAN网络对不同内核轮流训练。采用MCTS的策略进行模型训练。为了避免模型收敛或者梯度消失，MCTS的策略层应当被充分优化。在这里，我们不希望模型的目标仅仅是赢下比赛，我们更加希望模型可以从对局中学到什么。于是我们加入多维度的奖励机制，实时反馈给模型。取得了较为良好的效果。
2.奖励函数：赢下比赛，平局，游戏步长奖励。即时进攻奖励。
3.config文件配置：奖励机制及奖励参数。自适应训练机制【当某个agent的胜率低于此值时，增加其训练量】。回退模型【因为我们在一个cycle先训练white，再训练black。所以， Black的表现是在一个cycle中进行比较，而White的表现是基于上一个cycle对black的训练时white的胜率进行比较//训练white后应当判断训练后的white与训练前的white的指标好坏】。催促进攻设置【进攻率（*定义），进攻效率目标（0-1），进攻率低于此值时增加进攻奖励，奖励大小】。训练配置【cycle，T，etc】
4.加速优化策略：每N局游戏训练一次，每T局游戏保存一次日志，并行游戏批次（我用的是8）
